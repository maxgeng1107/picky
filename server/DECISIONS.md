# 保留与移除的依据

比较基线：main@94bf628（已含 Drive 备份、胶卷同步和练习命中率），待整理分支：1471647。

| 项目 | 处理 | 证据/理由 |
|---|---|---|
| 当前默认计数器、通用分数、选片和 VLM 提示词 | 保留 | 新排序器没有真人优势证据；100 轮相同反馈的算法回归测试与旧版一致。 |
| 新个人排序器、固定锚点评分 | 仅保留实验 | 模拟测试不是完整 VLM 对照，不证明更适合真实用户。 |
| 替换手机默认排序器、升级默认评分输入分辨率 | 撤回 | 没有对应真人结果；默认 512px/0.7 输入和原评分定义保持一致。 |
| Drive JPEG 备份和空间释放 | 保留并校验 | 它已在 main 存在；不因我们的旧分支而回退为完全禁用。校验 Drive 返回的文件 ID、MD5 和大小后才允许删除。 |
| Drive 未配置仍直接删照片的 fallback | 移除 | 不满足“备份成功再删”的约定；缺配置、错误、取消均不调用删除。 |
| 偏好持久化、损坏恢复、重新选片保留偏好 | 保留 | 回归测试覆盖存储往返、损坏主快照和另一轮处理。 |
| 默认计数器的混合证据解释 | 改文案，保留算法 | “Mixed evidence”描述观测，不把计数接近断言为“不在乎”。 |
| 内容缓存、响应完整性校验、超时/次数上限、旧点击防护 | 保留 | 缺失/重复 ID、截断响应、缓存无效、重复请求、预算、旧点击均有测试。 |
| 额外的 3001 服务和重复手机实现 | 移除 | 手机 Expo API 和单独的真人实验已覆盖所需入口。 |
| 主分支新增胶卷同步、OAuth 配置脚本、练习命中率 | 保留 | 同步修复新照片检测；命中率明确标为练习集而非独立测试，按照片 ID 保留标记，仅实际证据变化增加学习步数。 |
| 类型/lint 修复和忠实展示备份状态 | 保留 | 全仓检查；未上传、已备份、已删除分别显示。 |

Drive 上传保存的是 JPEG 副本；HEIC 原格式、原始元数据和 Live Photo 动态内容不保证保留。原图删除前明确说明，并保留系统确认。文件的 30 天 expiresAt 仅是元数据，尚未实现自动清理。

当前验证使用假的服务响应，不消耗真实 API。真实 Google/Anthropic、iPhone 权限/删除、拍摄场景与真人偏好仍需验收。默认算法不退回未合并前的工程缺陷，也不因模拟指标而宣称新排序器更准。
