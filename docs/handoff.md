## 3. 产品流程：LLM 是眼睛，代码是记性

| 步骤 | 谁做 | 做什么 |
|---|---|---|
| ① 筛照片 | 代码 + Claude | 只拿**今天**拍的、**画面里有人**的照片，按拍摄时间分成场景 |
| ② 看照片 | **Claude**（每个场景调用 1 次） | 淘汰闭眼、糊掉、没有人的照片；其余每张在 8 个维度上打 1–5 分（同一场景内相对比较） |
| ③ 挑照片 | 代码 | 对你的得分 = Σ 偏好权重 × (分数 − 3)，按得分排序，每个场景留 1–3 张（§4） |
| ④ 问你 | 代码 | 拿不准时发通知，A vs B |
| ⑤ 学习 | 代码（不调 Claude） | 赢家和输家逐维度相减，分差 ≥ 2 → 「选了它」+1；≤ −2 → 「没选它」+1 |
| ⑥ 更新状态 | 代码 | 多 2 次以上 → 确定（绿）；证据 ≥ 3 但两边差不多 → 不在乎（灰） |
| ⑦ 下一个场景 | 代码 | 用新偏好重新排序，不用再调 Claude |

偏好权重：确定 +2 · 倾向 ±1 · 避免 −2 · 不在乎 / 无证据 0。

**为什么不让 Claude 改偏好：** 它编的数字不可信；代码算才是真实计数、即时更新、成本低（每个场景 1 次调用，80 张的一天约 4–5 次）。

**8 个维度：** 面板显示 6 个：face looks smaller、clean jawline、eyes look bigger（美感）· facing the camera、big smile with teeth、shot from slightly above（风格，没有好坏）。参与打分但不显示 2 个：lighting、expression。完整定义见 `docs/backend-spec.md`。

## 4. 已确定的决定

1. **目标用户：** 一次拍几十张、只 P 几张发出去的年轻女生，作为第一步切入的人群；产品本身不按性别设门槛。
2. **Claude 只打分，代码负责挑选和学习**（§3）。
3. **只处理今天的照片，只处理有人的照片。** 风景、美食、截图完全不碰：不打分、不进 Cloud Bin、不删除。只有拍到人的照片才会走打分、备份到云端、挑选这套流程。
   - 「是不是用户本人」：iOS 据我们所知不对第三方 app 开放人物识别。demo 用 **Picky Demo** 相册，只放单人照；多人合照不在范围内。真产品可以在第一次使用时让用户选 3 张自己的照片作为参考。
4. **每个场景留多张，不是一张：** 留下所有和第一名得分相差 ≤ 2 的照片，**最少 1 张、最多 3 张**；几乎一样的连拍只留一张；用户经常选「Keep both」→ 上限自动调高。接口已经支持（`keptIds` 是数组，`/api/select` 有 `keep` 参数）。
5. **夜间整理 + 通知：** iOS 不能在拍照的瞬间唤醒 app，真实产品在夜里充电时处理；demo 用「Simulate tonight」按钮模拟，通知是真的。
6. **拍照提示：** 今天做「拍照指南」卡片（按学到的偏好生成，比如「往后退两步，用 2×，镜头略高于眼睛，角度随意」）；**相机里实时提示**需要逐帧分析，Expo Go 不支持，作为 pitch 里的「下一步」。
7. **不爬 Instagram / TikTok**（违反条款、做不完、法律风险）；**不用任何人的历史照片**。
8. **Claude API key：** 和 Max 另一个项目共用一个 key，只放在 `server/.env`，不进仓库。

## 8. 评委 Q&A 要点

- **LLM 起什么作用？** 它是眼睛：看出以前只有人能看出的东西（这张显不显脸小）。代码是记性：记住你在乎什么。
- **为什么大公司不做？** 他们可以做，这说明需求存在；但自动删照片对他们是责任风险，给长相打分是公关风险，所以只用通用标准。
- **身材焦虑？** Picky 从不评价你长什么样，只学你在**自己的**照片里更喜欢哪张；分数只在同一场景内比较，不展示给你。
- **有什么新的？** 专业摄影师有学个人风格的选片工具（Aftershoot、Imagen）；普通人只有通用的「挑最好」app（Picker AI、Tinder Photo Selector）。我们没找到面向普通人、学你个人规则、还能说出规则的产品（措辞用 "We couldn't find…"，不说 first）。
- **数据太少能学会吗？** 视觉模型已经会看图，Picky 只学你在 8 件事上各看重多少，几次选择就能看出趋势。
- **成本？** 每个场景 1 次 Claude 调用，学习是纯代码。
- **只做女生？** 第一步切入的人群，学习引擎不分人群，以后可以扩展。
